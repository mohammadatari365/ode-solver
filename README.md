# حل گامبهگام معادلات دیفرانسیل (ODE / IVP)

برنامه ای کاملاً آفلاین و تک فایلی برای حل و توضیح گامبهگام معادلات دیفرانسیل معمولی و مسائل مقدار اولیه، به زبان فارسی.

**نویسندگان:** Tahereh Esmaeilpour and Mohammad Hossein Attari  
**شناسه:** [@mmd_atari](https://github.com/mmd_atari)

## اجرا
کافی است فایل `ode-solver.html` را در مرورگر باز کنید. نیازی به سرور، اینترنت یا نصب هیچ کتابخانهای نیست.

## امکانات
- حل معادلات مرتبه ۱ تا ۵
- ورود جداگانه ضرایب `y`، `y′`، `y″` و ...
- تشخیص خودکار روش: خطی، برنولی، ریکاتی، کلرو، تفکیک پذیر، همگن، کامل، کوشی–اویلر، ضرایب نامعین، تغییر پارامترها، کاهش مرتبه و ...
- محاسبه ثوابت `C₁ … Cn` با شرایط اولیه
- توضیح کامل فارسی مراحل حل وmethods جایگزین
- صفحه کلید ریاضی داخلی با ساختارهای تصویری (توان، کسر، ریشه، قدر مطلق، تابع)
- تم سایبرپانک با فونتهای داخلی (Vazirmatn + Orbitron)
- چاپ / ذخیره به PDF

## ساختار پروژه
- `ode-solver.html` — محصول نهایی تک فایلی
- `src/` — موتور جبر نمادین و رابط کاربری
- `ui/` — قالب HTML و استایلها
- `assets/` — فونتهای داخلی
- `build.js`, `build-fonts.js` — اسکریپت ساخت فایل نهایی
- `test/` — تستهای موتور

## بازسازی فایل نهایی
```bash
node build-fonts.js
node build.js
node test/run.js
node test/verify.js
```
